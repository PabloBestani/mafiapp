# Assets de marca

## `mafiapp-card-back.jpg`

Lomo de las cartas físicas de MafiApp. Es la fuente visual principal para la identidad V1.

Usos recomendados:

- splash screen;
- pantalla de inicio;
- estado vacío de "sin partida en curso";
- thumbnail de configuración de partida;
- referencia visual en documentación y presentaciones.

No usar como fondo permanente de pantallas operativas: puede competir con información secreta, votos, estados y acciones nocturnas.
